# AutoParts-Shop 🚗🔧

**AutoParts-Shop** — это полнофункциональное веб-приложение для автоматизации работы магазина автозапчастей. Проект разработан в рамках курсового проекта по дисциплине «Технологии разработки программного обеспечения».

## 🌟 Основные возможности
- **Ролевая модель:** разграничение прав доступа (Администратор, Продавец, Поставщик).
- **Каталог запчастей:** удобный поиск, фильтрация и карточки товаров с указанием остатков.
- **Умный подбор аналогов:** графовый алгоритм (BFS) для поиска прямых и косвенных замен (кросс-номеров).
- **Оформление продаж:** корзина, автоматическое формирование чеков и списание остатков со склада.
- **Панель администратора:** управление запчастями, поставщиками, марками и моделями авто.
- **Личный кабинет поставщика:** просмотр профиля компании и статуса своих поставок.

## 🛠 Стек технологий
**Backend:**
- Python 3.12
- FastAPI (ASGI-фреймворк)
- SQLAlchemy (ORM)
- Pydantic (Валидация данных)
- PostgreSQL (База данных)
- JWT (Аутентификация и авторизация)

**Frontend:**
- HTML5, CSS3
- Vanilla JavaScript (ES6+)
- Fetch API (Взаимодействие с бэкендом)

## 🚀 Как запустить проект локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Alex-IST-386/AutoParts-Shop.git
   cd AutoParts-Shop
   ```

2. Создайте и активируйте виртуальное окружение:


```bash
python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
.venv\Scripts\activate     # Для Windows
```


3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Настройте базу данных PostgreSQL 
(создайте БД и укажите строку подключения в backend/database.py).

5. Запустите сервер FastAPI:

```bash
cd backend
uvicorn main:app --reload
```


6. Откройте frontend/html/index.html в браузере (рекомендуется использовать Live Server или запустить через локальный веб-сервер).
